## T1 自我介绍

**骨架**：锚点 → 现在 → 过去（一条相关积累）→ 未来（指岗位）

- 锚点：`我是【方向】做了【N】年的【岗位】，目前在【公司】【一句话业务】。`
- 现在：`我主要负责【范围】，最近一件拿得出手的事是【动作】+【数字】。`
- 过去：`再往前我在【公司/阶段】积累的是【与 JD 直接相关的一项能力】。`
- 未来：`所以我这次看的是【岗位类型】，贵司【具体业务/阶段】正好是我想继续做深的方向。`

**示例（后端 5 年）**：我是做 B 端 SaaS 后端五年的工程师，现在在 X 公司负责订单中台。去年 Q3 我把下单链路重做了一遍，P99 从 800ms 压到 180ms，大促当天零超时。再往前两年我做的是支付对账，这块让我对资金一致性特别敏感。所以这次我看的是交易方向的岗位，贵司正在扩的跨境结算正好是我能直接上手的地方。

**扣分点**：按简历时间线复述；从大学讲起；通篇没有数字；结尾不谈岗位只谈自己。

## T2 项目深挖 / 最有成就感的事

**骨架（STAR-Q，五段）**

1. 背景一句：`【什么业务】【多大规模】【当时的难点一句话】。`
2. 我的角色：`我是【主 R / 唯一负责 X 模块】，团队【N】人。`
3. 关键动作 2–3 个（动词开头 + 取舍）：`我先【做法 A】因为【理由】；然后【做法 B】，这里放弃了【方案 C】，代价是【X】，但换来了【Y】。`
4. 结果（数字 + 对比）：`上线后【指标】从【A】到【B】，【副作用指标】没恶化。`
5. 复盘一句：`如果重做，我会在【环节】提前【改进动作】。`

**追问弹药（提前准备）**：为什么不用 B 方案？你个人的贡献占比多少？最大的风险点当时怎么兜的？

**扣分点**：只讲"我们"不讲"我"；把项目说明书念一遍没有取舍；结果全是形容词没有对比；复盘说"没有遗憾"。

## T3a 优点

**骨架**：`结论词 + 一个场景 + 数字 + 对岗位的作用`

`我最强的是【一个具体能力，如"把模糊需求拆成可交付的排期"】。上一份工作里【场景】，我【做法】，结果【数字】。这个能力放在这个岗位上，正好对应 JD 里【那一条】。`

**扣分点**：形容词堆砌（"认真负责、抗压能力强"）；举的例子和岗位无关。

---

## T3b 缺点

**骨架**：`真实但不致命 + 已经采取的动作 + 现在的进展`

`我比较明显的是【缺点，如"对不熟的领域容易先动手再查文档"】。吃过一次亏：【具体后果】。之后我固定了两个动作：【动作 1】【动作 2】，现在【可验证的改善】。`

- 可用方向：过度关注细节导致排期紧、公开表达偏弱、对新工具上手慢、拒绝人时不够果断。
- **禁用**："我太追求完美""我太拼命工作"——面试官会判定为不真诚。

**扣分点**：说的是伪缺点；只承认不改进；改进没有证据。

---

## T4 离职原因 / 为什么看机会

**骨架（三段式，不带情绪）**

1. 肯定：`在【公司】这两年我最大的收获是【一项能力/一个成果】。`
2. 事实驱动：`现在的问题是【客观事实：业务线收缩 / 技术栈方向变了 / 岗位职责被拆走 / 想聚焦 X 但这里做不到了】。`——只说事，不评价人。
3. 指向对方：`我下一份想解决的是【X】，贵司【具体业务】正好在做这件事。`

**禁忌说法**：骂前领导或团队；说"钱少"（钱单独在 T7 谈）；说"公司太乱"；说"想换个环境"（等于没说）。

**扣分点**：情绪外露；原因和 T5 的动机对不上；把离职说成"被逼走"。

## T5 为什么选我们

**骨架（三匹配，必须有 1 个"只有做过功课才知道"的细节）**

- 公司：`贵司现在处在【阶段/业务动作，如"从单点工具往平台走"】，这个阶段最需要的是【能力】。`
- 岗位：`JD 里【第 1 条】和【第 2 条】，正好是我【证据 + 数字】做过的事。`
- 我：`我能补的是【具体缺口】，因为【证据】。`

**扣分点**：只夸"贵司是行业龙头、氛围好"；把公司介绍复述一遍；说不出任何具体产品或近期动作。

## T6 职业规划

**骨架**：短期（1 年，可交付）→ 中期（3 年，深一个方向）→ 长期（5 年，不影响这个岗位）

`一年内我想做到的是【上手 + 一个明确交付】；三年我想在【方向】上做到能独立定方案；再远我希望是【纵深，而不是换赛道】。`

- **禁用**："我想三年内创业""我想尽快转管理"（除非岗位就是管理岗）——会让面试官担心稳定性。

**扣分点**：规划和岗位不在一条线上；只说"跟着公司发展"；说得太具体到某个职级承诺。

---

## T7 薪资期望

**骨架**：现状结构 → 期望区间 → 弹性条件

`我现在的总包是【N】，构成是【base / 奖金 / 期权】。基于这个岗位的职责和市场情况，我的期望区间是【A–B】。如果【总包结构 / 职级 / 成长空间】合适，区间是可以谈的。`

- 被追问"给不到怎么办"：`如果整体差距在【X%】以内，我更看重【岗位成长/团队】，可以再谈；差太多的话我可能需要再考虑。`
- **禁用**：先报一个死数；说"都可以，按公司标准来"（会被压到底）；拿别家 offer 施压。

**扣分点**：区间上下浮动超过 30%（等于没底）；不了解当地市场价；把上一家薪资当唯一依据。

## T8 行为题通用（STAR-R）

**骨架（90–120 秒）**

- S 一句：`【时间/场景】，当时【目标/约束】。`
- T 一句：`我要做的是【具体任务】，卡点是【难点】。`
- A 三句：`我做了三件事：一【动作】；二【动作】；三【动作】。`（动词开头，体现判断）
- R 数字：`结果是【指标 A→B】，【副作用】可控。`
- R 反思：`这件事让我固定下来一个习惯：【X】。`

**示范**：要举例时直接引用 `../vendor/interview-coach/references/star_examples.md` 里的完整范例（领导力 / 解题 / 冲突 / 失败 / 压力各一段，英文原文），不要自己另编一段。

**扣分点**：S 讲 3 分钟；A 全是"我们"；R 没有数字；讲成了流程说明书，没有你的判断点。

## T9 冲突 / 难搞的同事 / 跨部门推不动

**骨架**：冲突不是人，是目标/信息/优先级不一致

`分歧在【目标不一致，不是谁对谁错】。我先【对齐共同目标】，再【用数据/用户反馈摆事实】，然后【给对方两个可选方案】。最后【结果】，而且后面【合作反而更顺】。`

**扣分点**：暗示"我没错，是他不行"；把冲突讲成职场宫斗；没有结果；说"我就去找领导了"（除非走投无路并说明为什么必须先找）。

---

## T10 失败 / 犯错

**骨架**：选真失败（不涉诚信/安全）→ 我的决策点 → 后果（不自贬）→ 补救 → 机制化改进

`我搞砸过【事】。当时我判断【错在哪】，实际是【真实原因】。后果是【具体损失】。我做了【补救】，之后我把【流程/检查项】固化下来，后来同类问题【再没发生/发生了 X 次】。`

**扣分点**：假失败（"我太追求完美"）；把锅推给外部；改进只停在"我以后会注意"。

---

## T11 压力 / 多任务 / 加班

**骨架**：承认现实 → 排序方法 → 一个真实案例 → 边界

`同时压过来的时候我不靠加班解决，靠排序：按【影响 × 紧急 × 成本】排，先和【相关方】确认哪件事可以晚。上个季度我手上【N】件事，我把【A】往后推了两周，先保【B】，结果【数字】。真要赶节点我也会加班，但那是例外不是常态。`

**扣分点**：空喊"我抗压能力很强"；说"我从不加班"（不可信）；抱怨前公司加班。

## T12 反问环节

**三个必问（按顺序挑 2–3 个）**

1. `这个岗位入职后六个月内，最重要的一件交付是什么？`
2. `团队现在最大的瓶颈是人手、需求，还是技术债？`
3. `如果我入职，前三个月你会用哪几件事判断我做得对不对？`

**可选补充**：`这个岗位是新增还是补位？如果是补位，上一位同学的主要挑战是什么？`

**禁用**：一上来问薪资福利年假；问"我今天表现怎么样"；说"我没有问题"。

## T13 刁钻题（学历 / 空窗期 / 跳槽频繁 / 转行 / 年龄婚育）

**骨架（四步，别防御）**

1. 直接答，不回避：`是的，我【事实】。`
2. 一句原因：`原因是【客观原因】。`
3. 给证据：`这段时间我做成了【事 + 数字】，所以【能力】上我没有断档。`
4. 拉回岗位：`这和我现在要做的【岗位职责】是接得上的。`

- 空窗期：`我用了【N】个月【学习/家庭/项目】，其中【产出】。`
- 跳槽频繁：`前两次是我判断错了方向，第三次开始我明确了要看【X】，所以这次我特别看重稳定做深。`
- 转行：`我转的不是行业，是同一套【能力】换了个场景用。`
- 婚育/年龄：只答边界，`我目前的状态是【事实】，不影响【出差/加班/稳定性】。`——不展开、不道歉。

**扣分点**：解释超过 30 秒（越解释越像掩饰）；反问"这跟工作有关系吗"；编造理由。

## T14 技术题口述

**骨架（60–90 秒）**：定义 → 原理 → 取舍 → 落地 → 边界

1. 定义一句：`【X】解决的是【问题】。`
2. 原理：`它靠【机制】做到，关键点是【A】和【B】。`
3. 取舍：`什么时候不用它：【场景】，因为【代价】。`
4. 落地：`我在【项目】里用它做过【事】，效果【数字】。`
5. 边界：`它的局限是【X】，我们当时用【Y】兜的。`

**扣分点**：背百科定义；只讲优点不讲代价；说不出自己用过的场景。

---

## T15 不会的题

**骨架（诚实 + 迁移 + 方法，别硬编）**

`这块我没有直接做过。我了解的部分是【相邻知识】，我理解它和【已知概念】的关系是【一句话】。如果现在要解，我会先【验证方法】，再看【指标】。方便的话给个提示，我顺着往下推。`

**扣分点**：沉默；硬编一个错答案；只说"我没学过"就停（等于放弃）。

## T16 案例 / 估算

**骨架（五步）**：澄清 → 公式 → 假设 → 结论 → 检验

1. 澄清：`我先确认范围：【地域/时间/口径】。`
2. 公式：`我用【自上而下 / 自下而上】，拆成【3–5 个相乘的因子】。`
3. 假设：`每个因子取【数字】，理由是【一句】。`
4. 结论：`所以大约是【数量级】。`
5. 检验：`和【已知基准】比，偏高/偏低，因为【原因】。`

**扣分点**：不澄清直接算；假设没有理由；算完不检验；纠结精确数字而不是量级。

## T17 "你还有什么要补充的"

**骨架**：补一个前面没讲到的证据 → 一句岗位匹配 → 一句意愿（克制）

`补一点前面没提到的：【一个和岗位直接相关的成果 + 数字】。这也是我觉得自己和这个岗位最对得上的地方。如果有下一轮，我很愿意继续聊【具体方向】。`

**扣分点**：重复前面的内容；突然开始煽情表忠心；说"没有了"。

## 兜底四段骨架

`结论一句（我的答案是什么）→ 证据一件（我做过的 + 数字）→ 取舍一句（代价/边界）→ 回扣岗位一句（所以对这个岗位意味着什么）。`
